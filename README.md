# 🏋️‍♂️ Fitness Exercises App 

A modern, responsive fitness exercises web application built with **React 18**, **Material UI**, and **RapidAPI**. The app allows users to explore over **1000+ exercises**, filter by muscle groups and body parts, view detailed exercise instructions, watch related YouTube videos, and discover similar exercises.

This project was built to demonstrate real-world React development, API integration, and clean UI/UX practices.

---

## 🚀 Live Demo

🔗 (https://fitness-app-x819.vercel.app/)

---

## ✨ Features

*  Search exercises by name
*  Filter by body part, target muscle, and equipment
*  Detailed exercise pages with animated GIFs
*  Related YouTube exercise videos
*  Similar exercises recommendations
*  Pagination for large datasets
*  Fully responsive design (mobile & desktop)
*  Modern UI using Material UI v5

---

## 🛠️ Tech Stack

**Frontend**

* React 18
* Vite
* Material UI (MUI v5)
* React Router v6
* Axios

**APIs**

* ExerciseDB API (RapidAPI)
* YouTube Search API (RapidAPI)
